## 検証結果

- Windows PowerShellから`go test ./...`、`go vet ./...`成功。
- WSL2 Ubuntuで`go test ./...`、`go vet ./...`、`go test -race ./...`成功。
- 保存済み日付の回帰シードを追加したFuzzDecodeが約7秒・60,686実行で成功。網羅性の証明ではない。
- WSLのWindowsドライブ（stat表示v9fs）をTMPDIRに指定した`go test -count=1 ./internal/storage`成功。
- PowerShell 5.1／7で呼び出し位置を変えたビルドとライセンス収集成功。実行ファイルとライセンスは検証用の.work以下に出力。
- 6対象のZIP作成、SHA256照合、ZIP整合性、英日文書・LICENSE・入れ子の依存ライセンス・Unix実行権限を検査。展開後のLinux amd64版の`--version`成功。パッケージはスクリプト動作確認用で、公開していない。
- Bash構文検査、actionlint v1.7.12の静的検査、英日README・マニュアルのリンク／見出し／コードフェンス検査成功。
